Validador de CPF - C# (.NET 10)
Sobre o projeto:
Este é um projeto simples desenvolvido para praticar os conceitos básicos de programação em C# utilizando Windows Forms (.NET 10).
A aplicação permite que o usuário digite um CPF e verifique se ele é válido através do cálculo dos dígitos verificadores.
Este projeto foi desenvolvido durante meus estudos de programação e contou com a ajuda de um amigo em alguns momentos para entender melhor a lógica e a estrutura da aplicação.

--Funcionalidades
Verificar se um CPF é válido
Limpar os campos da tela
Encerrar a aplicação
Interface gráfica simples utilizando Windows Forms

Como funciona

-1. Digite um CPF
O usuário informa o CPF no campo de texto.

-2. Clique em "Verificar"

O sistema:
Remove pontos e traços
Calcula os dois dígitos verificadores
Compara com o CPF informado

-3. Resultado
O sistema exibe:
ESSE CPF VALIDO
OU
CPF INVALIDO

Botões da aplicação
Verificar--
Realiza a validação do CPF informado.
Limpar--
Limpa o campo de CPF e o resultado da validação.
Sair--
Fecha a aplicação.
